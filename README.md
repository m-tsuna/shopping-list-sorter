# 買い物リスト自動仕分け

思いついた買い物の品物を、iPhone から声か短い入力で登録すると、リマインダーのお店別リストへ自動で入れるツールです。

- ルールにある品物は、確認なしでお店のリストに入ります
- ルールにない品物は、AI（OpenAI gpt-4o-mini）がお店を考えて確認し、決まったお店を覚えます
- 毎日使う部分は iPhone の「ショートカット」で動きます。Python は Mac で、ルール作り・整理・正解率の測定に使います

## 事前準備

1. Python 3 を用意し、`pip install -r requirements.txt` を実行する
2. `.env` を作る（下の「秘密ファイルの用意の仕方」）
3. iPhone と Mac で同じ Apple アカウントの iCloud Drive を使う
4. リマインダーに6つのリストを作る：スーパー、ドラッグストア、100均、アカチャンホンポ、コストコ、ネットショッピング
5. 買い物メモを `memo.txt` に保存する。`⚫︎` で始まる行がお店、それ以外の行が品物です

```
⚫︎スーパー
牛乳
⚫︎コストコ
トイレットペーパー
```

## 秘密ファイルの用意の仕方

OpenAI の管理画面で API キーを作り、このフォルダに `.env` を作って次の1行を書きます。`.env` は GitHub に載せません。

```
OPENAI_API_KEY=ここに鍵
```

鍵はショートカットの中にも入れます。**ショートカットは人に共有しないでください。** スクリーンショットでは鍵を隠し、OpenAI の管理画面で使いすぎの上限を確かめてください。

## 使い方（Python）

| コマンド | すること |
|---|---|
| `python main.py deploy` | `settings.json` を iCloud にコピーする（聞き方を変えたときも実行） |
| `python main.py create` | `memo.txt` から `rules.json` を作る |
| `python main.py tidy` | 書き方の違う品物を AI が見つけ、お店を揃える |
| `python main.py test` | `test_items.csv` で AI の正解率を測る（少し料金がかかる） |
| `python main.py always 品物` | 買うお店が変わる品物を、毎回お店を選ぶようにする |
| `pytest` | 単体テストを実行する（AI にはつながない） |

`rules.json` は Mac の次の場所に作られます。

`~/Library/Mobile Documents/iCloud~is~workflow~my~workflows/Documents/買い物仕分け/`

## ショートカットの取り込み方（おすすめ）

1. Mac で `python build_shortcut.py` を実行する（署名付きの `買い物に追加.shortcut` ができる）
2. できたファイルを iCloud Drive に置き、iPhone のファイルアプリでタップして追加する
3. 鍵を聞かれたら貼り付ける
4. 編集画面の下の方にある6つの「品物 を スーパー に追加」で、「もしも」のお店と同じリストを選ぶ
5. `rules.json` を開けないと出たら、ファイルアプリで `rules.json` と `settings.json` を一度タップしてダウンロードするか、アクションのフォルダを選び直す

## ショートカットの作り方（手で作る場合）

ショートカットアプリで新しいショートカットを作り、名前を「買い物に追加」にして、次の順にアクションを並べます。アクションの名前は検索欄で探します。iOS の版で名前が少し違うことがあります。

**1. 品物を受け取る**

1. 「入力を要求」：種類はテキスト、質問は「何を買いますか？」
2. 「変数を設定」：名前は `品物`
3. 「もしも」：`品物` が「値がない」なら「ショートカットを停止」

**2. ファイルを読む**

4. 「フォルダからファイルを取得」：保存先は Shortcuts、パスは `買い物仕分け/rules.json`
5. 「テキストを取得」→「変数を設定」：名前は `ルール文字`
6. 「辞書を取得」（入力は `ルール文字`）→「変数を設定」：名前は `ルール`
7. 「フォルダからファイルを取得」：パスは `買い物仕分け/settings.json`
8. 「辞書を取得」→「変数を設定」：名前は `設定`
9. 「辞書の値を取得」：`ルール` から、キーは `品物` →「変数を設定」：名前は `決まったお店`

**3. お店を決める**

10. 「もしも」：`決まったお店` が「値がある」
    - 「変数を設定」：`お店` に `決まったお店`
11. 「そうでない場合」の中に次を入れる
    - 「辞書の値を取得」：`設定` のキー `stores` →「テキストを結合」：区切りは `、` → 変数 `お店の一覧`
    - 「辞書の値を取得」：`設定` のキー `prompt`
    - 「テキストを置換」を3回：`{stores}` → `お店の一覧`、`{examples}` → `ルール文字`、`{item}` → `品物`。結果を変数 `聞き方` にする
    - 「URLの内容を取得」：URL は `https://api.openai.com/v1/chat/completions`、方法は POST
      - ヘッダ：`Authorization` に `Bearer 鍵`
      - 本文は JSON：`model` = `gpt-4o-mini`、`temperature` = 0（数値）、`max_tokens` = 20（数値）、`messages` = 配列の中に辞書1つ（`role` = `user`、`content` = `聞き方`）
    - 「辞書の値を取得」：キーは `choices.1.message.content` → 変数 `AIの答え`
    - 「もしも」：`AIの答え` に値があり、`お店の一覧` が `AIの答え` を含む
      - 「メニューから選択」：質問は「`AIの答え` でいいですか？」、項目は「はい」「ほかのお店を選ぶ」
      - 「はい」：`お店` に `AIの答え`
      - 「ほかのお店を選ぶ」：「リストから選択」（`設定` の `stores`）→ `お店`
    - そうでない場合：「リストから選択」（`設定` の `stores`）→ `お店`
    - 「辞書の値を設定」：`ルール` のキー `品物` に `お店`
    - 「ファイルを保存」：保存先は Shortcuts、サブパスは `買い物仕分け/rules.json`、「保存先を尋ねる」はオフ、「上書き」はオン

**4. リストに入れる**

12. お店ごとに「もしも」：`お店` が「スーパー」なら「新規リマインダーを追加」（内容は `品物`、リストはスーパー）。6つのお店の分だけ繰り返す
13. 「通知を表示」：「`お店` に `品物` を入れました」

**5. 開きやすくする**

- ショートカットの共有メニューから「ホーム画面に追加」する
- ロック画面のウィジェットにショートカットを追加する
- Siri には「買い物に追加」と話しかける

## 注意

- お店を増やすときは、`settings.json` を直して `deploy` し、ショートカットの手順12も増やします
- 間違って覚えたルールは、ファイルアプリで `rules.json` を直します
- 1回に入れられるのは1品です
